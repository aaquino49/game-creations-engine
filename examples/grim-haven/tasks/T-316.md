3. Post-process with the task script to 512x512 RGB, flat `#361515` background, framing box; overwrite the PNGs only, confirm each existing `.import` has mipmaps/generate=true, re-import.
4. Write the ledger fragment, delete the superseded one(s), run `python game/tools/build_asset_index.py`, build the contact sheet and framing check, capture the `enemy_inspect_widget` scenario, run the full suite.

### Pitfalls
- Do not reuse, trace or overpaint the existing procedural busts. Do not touch `res://data/enemies.json`, any sprite, any `.gd` file, any hero bust or another batch's files.

- Every listed PNG is a genuine image-generation painting (PROMPTS.md names the image tool and the exact prompt per file; raw originals kept in the originals folder); no bust is drawn by code
