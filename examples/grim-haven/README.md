# Grim Haven examples

Real files from the game that proved the engine (a Darkest Dungeon × XCOM tactics game, Godot 4.7, October 2026). Copy the shape, not the content.

| File | What it shows |
|---|---|

| [ART_GUIDE.md](ART_GUIDE.md) | A full art direction: v1 1-bit backbone, then the v2.0 overhaul (32 px 3/4 pixel art, palette, painted portraits, CC0/CC-BY sources, image-generation rules) |
| [OWNER_REQUESTS.md](OWNER_REQUESTS.md) | How the owner steered a running team: requests R-1..R-7, including follow-ups that gate the final release |

| [config.json](config.json) | The live orchestrator config at capture time, with dated `_notes` explaining each model change (ntfy topic removed) |
| [tasks/T-008.md](tasks/T-008.md) | A code brief approved on attempt 1: exact API, formulas, files, tests |
| [tasks/T-253.md](tasks/T-253.md) | The v2 vertical-slice art brief (sprites, tiles, painted portrait) |
