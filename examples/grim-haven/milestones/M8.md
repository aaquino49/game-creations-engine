# M8 complete: Final wrap-up, ship v1.3.0 (final report)

2026-10-17, PLAN 20261017-154301. Every M8 board task is done or dropped
(21 done; T-243 and T-244 dropped as known issues). T-182 final balance,
T-183 full regression QA and T-184 final Windows export are all approved.
The final build is `builds/GrimHaven.exe`, version 1.3.0 (Windows
metadata 1.3.0.0). M8 is the owner's last milestone (OWNER_REQUESTS R-1),
so the team stops here. The one M9 task (T-245) was dropped because R-1
rules out M9.

## What shipped in M8

- Final balance pass (T-182): the bot ran 19 cases x 16 seeds with 0 errors
  and 0 timeouts. Every M7 timing guide was met, so no numbers changed.
  The report is project/balance/M8_BALANCE_REPORT.md.
- Player-facing polish: hero-sheet Death Blow resistance shows the campaign
  difficulty (T-215). Expedition provision names, quantities and the Steps
  counter stay readable (T-216). Combat-log disease names use display names
  (T-229). The camp panel text is bigger and long hero names wrap (T-231).
  The title Settings modal is centered (T-238). The campaign-over Survivors
  line wraps (T-240). Skill-button tooltips show real numbers instead of
  {dmg}/{range} (T-242, owner R-2).
- Tooling and test health: headless --screenshot runs exit promptly (T-224).
  The autosave live-probe leak was diagnosed and its leak assertion fixed
  (T-230). Layout probes were added (T-222). Six phase regression harnesses
  cover frontend, Haven/Clinic, expedition/camp/infection, combat, victory
  and siege (T-232..T-237, T-239). The combat harness uses the chosen
  difficulty's data (T-241, owner R-2).

## The whole game, v1.0 to v1.3

- v1.0.0 (M1-M5): grid tactics with cover, flanking, LOS, initiative and
  stress. Six classes. Raiders, Blighted and Rust Legion factions with
  lieutenants and a two-phase Saint Ferro finale. Expedition room graphs with
  curios, provisions and loot. The Haven hub: recruiting, Clinic, upgrades,
  the Radio Tower mission board, weekly doom, raids and the Siege of Haven.
  Campaign victory and defeat screens, audio and music, How to Play, Credits,
  and an autosave slot.
- v1.1.0 (M6): Settings (volumes, window scale), Drifter difficulty, combat
  feel (hit flash, death fade, knockback, screen shake), HUD and AI fixes.
- v1.2.0 (M7): rest-site camping with class skills, six persistent diseases
  and Clinic cures, five regional battlefields, four curios, four trinkets.
- v1.3.0 (M8): the polish, balance and regression work above.

## Known issues

- T-243 (dev only): DevTools --screenshot overrides --quit-frames. The tool's
  header documents this. Workaround: leave out --screenshot and use a high
  --quit-frames with capture_prefix PNGs. Players are not affected.
- T-244 (dev only): some headless test runs print "2 resources still in use
  at exit". Six earlier tasks never cleared this noise. Every gate is clean,
  and the game itself is not affected.
- T-245 (cosmetic): small text clipping. Long titled names are cut off on the
  Haven roster card. The expedition header has no left margin, and 'Steps: N'
  touches the right edge at 720p. The campaign-over Survivors line can wrap
  mid-name.
- Balance comes from the bot with disclosed fixtures, not from human
  playtests. Some late-game fights stay hard on purpose.
- Windows x86_64 only. One autosave slot. No controller support.
